# ML Problem Framing & Responsible Data Card — Submission Pack

## Files
- `ml-problem-framing-memo.md`: decision framing and recommendation.
- `responsible-data-card.md`: completed data card based on the supplied template.
- `customer-churn-baseline.ipynb`: executable educational notebook.
- `risk-register.csv` and `risk-register.md`: risk register.
- `customer-churn-training.csv`: supplied input dataset.

## Run the notebook
Install dependencies if needed:
`pip install pandas numpy scikit-learn jupyter`

Place all files in the same folder, then open `customer-churn-baseline.ipynb` in Jupyter or VS Code and run the cells.

## Important limitation
The dataset has only 12 rows. All model results are educational demonstrations, not reliable evidence of generalization. Provenance, permissions, target definition, and feature timing are not documented in the supplied files. Do not deploy a model from this dataset.
